# Netflix Clone

This is a Netflix clone project with main functionalities including user authentication, browsing movies, movie details, video player, search, and user profiles.

## Technologies Used

- Backend: Node.js with Express
- Frontend: HTML, Tailwind CSS, Google Fonts, Font Awesome, JavaScript
- Mock data for movies and users

## Setup and Run

### Backend

1. Navigate to the backend directory:

```bash
cd netflix-clone-backend
```

2. Install dependencies:

```bash
npm install express cors
```

3. Start the backend server:

```bash
node server.js
```

The backend server will run on `http://localhost:3001`.

### Frontend

1. Open the frontend files in your browser. For example, open `netflix-clone-frontend/index.html` in a browser.

2. Use the navigation links to browse, login, signup, and view movie details.

## Features

- User login and signup with mock authentication
- Browse movies with search functionality
- Movie detail page with video player
- User profile page with watchlist management

## Notes

- This is a demo project with mock data and no real database.
- Video streaming is simulated with sample video URLs.
- For full functionality, run the backend server and open frontend pages in a modern browser.
